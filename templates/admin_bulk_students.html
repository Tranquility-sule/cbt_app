Bulk Create Student Accounts

Upload a CSV with a name column (or a plain text file with one student name per line). Each student gets a unique registration number and a randomly generated password, so they can all log in independently and simultaneously on exam day. A spreadsheet with the generated logins will download automatically — keep it secure and distribute it to students before the exam.

If set, every student in this upload is tagged with this department. Use this together with a "Restrict to Department" exam setting to limit an exam to only these students.
